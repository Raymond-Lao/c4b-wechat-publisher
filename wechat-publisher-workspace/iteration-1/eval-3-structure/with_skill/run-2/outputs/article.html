多行引用

引用块的第一行。
引用块的第二行，这一行里面还有 加粗的重点。
最后一行收尾。

引用块最容易出的问题是多行被压成一行 —— 换行一旦丢了，引用就变成了一坨看不出层次的文字。

代码块

def convert(src, dst):
"""读 -> 清洗 -> 套样式 -> 写出"""
html = read(src)
html = sanitize(html)
write(dst, html)
return True

代码块要保留原始换行，否则缩进一丢，Python 就从可读变成了不可读。
