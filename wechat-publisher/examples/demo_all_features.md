## 高亮框 callout

::: note 什么是 callout
callout 就是公众号文章里那种**带底色和左侧竖线**的强调框。

它能让重点内容一眼跳出来，是最实用的排版元素之一。
:::

::: tip 使用建议
一篇 3000 字的文章，放 **2 到 4 个** callout 最舒服。

放太多反而会让读者抓不住重点。
:::

::: warn 注意
callout 内部**不能嵌套 callout**，也不要用 `<div>` 之类的标签 —— 公众号会剥离它们。
:::

::: practice 动手试试
在你的 Markdown 里写：

**:::** tip 标题

内容

**:::**

三个冒号开头，指定类型和标题，再三个冒号结尾。
:::
