## 结构元素大盘点

这一份稿子故意把分隔线、多行引用、代码块和表格都放进来，用来验证转换之后结构有没有走样。

---

### 多行引用

> 引用块的第一行。
> 引用块的第二行，这一行里面还有 **加粗的重点**。
> 最后一行收尾。

引用块最容易出的问题是多行被压成一行 —— 换行一旦丢了，引用就变成了一坨看不出层次的文字。

### 代码块

```python
def convert(src, dst):
    """读 -> 清洗 -> 套样式 -> 写出"""
    html = read(src)
    html = sanitize(html)
    write(dst, html)
    return True
```

代码块要保留原始换行，否则缩进一丢，Python 就从可读变成了不可读。

### 表格

| 元素 | 转换后应该是 | 常见故障 |
| --- | --- | --- |
| 分隔线 | 一行可见的分隔符 | 整条消失 |
| 引用块 | 带左侧竖线的多行块 | 压成一行 |
| 代码块 | 等宽字体保留换行 | 换行全丢 |
| 表格 | 带边框的表格 | 边框丢失 |
