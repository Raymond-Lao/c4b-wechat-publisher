## 高亮框演示

高亮框是公众号排版里最实用的元素，它能把重点内容从正文里拎出来。

::: note 什么是高亮框
高亮框就是带底色和左侧竖线的强调块。一篇长文里放 **2 到 4 个** 最舒服。
:::

::: tip 带**行内加粗**的标题
标题里的 markdown 加粗也应该正常渲染，而不是把星号原样显示出来。
:::

::: warn 注意嵌套
高亮框里不要放 HTML 标签，公众号会把它们剥掉。
:::

::: practice 动手试试
按顺序做三件事：
1. 先写下你原本的目标
2. 再记录实际发生的结果
3. 最后对比两者的差距

做完之后，你会发现问题通常不在执行力上。
:::

## 高亮框之后的正文

上面的四种类型分别是知识点、提示、警告和实践建议。它们各自有不同的底色和图标，混用的时候注意别让颜色太跳。
